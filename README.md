# 🔍 الباحث الذكي في نصوص الصور (Image OCR Search Agent)
أداة بسيطة لفحص الصور (بما فيها صيغ أبل HEIC) واستخراج النصوص العربية والإنجليزية منها مع دعم البحث المرن والمطابق وتغيير اللغة تلقائياً.

## طريقة التشغيل على Ubuntu و Windows:
1. تثبيت المكتبات:
   `pip install -r requirements.txt`
2. تشغيل البرنامج:
   `streamlit run app.py`
